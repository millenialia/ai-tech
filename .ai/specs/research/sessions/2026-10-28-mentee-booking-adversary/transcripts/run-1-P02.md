# Run 1 · P02 — Freelancer / solo contractor · Adversary
_Basis: [INTERVIEW: 2026-09-02-interview-freelancer-react.md]_

## Objections surfaced

[SYNTHETIC] **Profile describes experience, not answerable questions** — "experienced with React performance" ≠ "has estimated a CRA→Vite migration on a 60k-line codebase." Attacks A03. Fix: "I can help with" problem-type list on profiles.

[SYNTHETIC] **No sub-topic filtering** — search by stack returns generalists; can't filter by problem type. Attacks A05 (5-min booking). Fix: sub-topic tags ("bundler migration", "monorepo setup") mentors self-select.

[SYNTHETIC] **No same-day availability signal at browse time** — if no slot today, product is useless for the use case regardless of everything else. Attacks A01, A05. Fix: "available today" badge on search results.

[SYNTHETIC] **Quality risk on solo payer** — refund covers no-show; "useless answer" is non-refundable, with no ratings to pre-filter. Attacks A01. Fix: cancellation window, or binary "resolved/not resolved" for platform health only.

[SYNTHETIC] **Session interface undefined** — no indication of code paste support, syntax highlighting, file sharing. For technical debugging, a plain chat box wastes paid time. Attacks A06 (text resolves the use case).

[SYNTHETIC] **No accountability loop** — confident wrong answer has no mechanism; loss is entirely on the buyer.

## Why I would still not
Za 150 złotych z własnej kieszeni kupuję nadzieję, że ta osoba rozumiała dokładnie mój problem. Profil mówi mi, że pisała w React od pięciu lat. Dobra. Ja też. To nie jest to, co chcę wiedzieć. [SYNTHETIC]
