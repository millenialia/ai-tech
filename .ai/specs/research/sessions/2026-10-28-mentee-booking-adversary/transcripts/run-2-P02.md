## Objections surfaced

[SYNTHETIC] **No real-time availability signal** — no "online now" indicator; can't tell if a mentor is at their desk right now. Attacks A01, A05.

[SYNTHETIC] **Profile trust shallow for crisis scenario** — GitHub shows code history, not crisis-handling ability or communication speed under text pressure. Attacks A03, N02.

[SYNTHETIC] **Billing creates a client relationship problem** — even if session resolves the bug, the invoice is visible to the client. Attacks A01 for this segment specifically (solo contractor who keeps costs invisible to client).

[SYNTHETIC] **25-min fixed session misaligned with bug-fix time boxes** — live bugs don't fit 25-minute containers; no "extend" option. Attacks implicit session-length assumption.

[SYNTHETIC] **Cold-start context cost eats session** — stranger needs full setup time; a stressed explainer loses 10+ minutes on context before question lands. Attacks A06.

[SYNTHETIC] **No-show refund requires trust in unfamiliar platform** — "same-day refund" is only reassuring if you've seen it work. Attacks A01 on first use.
